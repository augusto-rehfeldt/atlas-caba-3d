# Atlas CABA 3D

## What This Is
Isometric 3D viewer of Buenos Aires CABA buildings (48 barrios), generated by Python build scripts.

## Non-Negotiables
- Build data is regenerated from `build_*.py` scripts — edit the script, not the output files.

## Commands
- Build: `python build_caba.py`
- View: serve directory and open `index.html` (e.g. `python -m http.server 8000`)
